# Swiggy Data Analysis Using Python

## About the Project
This project focuses on analyzing Swiggy food delivery data using Python and statistical methods. The notebook explores restaurant orders, cities, cuisines, average meal prices, customer ratings, food preparation times, and delivery rider distances.

## Objectives
- Explore and understand the dataset.
- Analyze food orders across different cities.
- Study cuisine types and average meal prices.
- Examine customer ratings.
- Analyze food preparation time and rider travel distance.
- Perform descriptive statistical analysis to understand the data.

## Technologies Used
- Python
- Jupyter Notebook / Google Colab
- Pandas
- Descriptive Statistics

## Dataset Description
The dataset contains food delivery order information with the following columns:

- `OrderID` – Unique order identifier
- `City` – City associated with the order
- `Cuisine` – Type of cuisine
- `Avg_Meal_Price_INR` – Average meal price in Indian rupees
- `Customer_Rating` – Customer rating
- `Preparation_Time_Min` – Food preparation time in minutes
- `Rider_Distance_KM` – Rider distance in kilometres

## Project Workflow
1. Import the required Python libraries.
2. Load the Swiggy dataset using Pandas.
3. Display and inspect the dataset.
4. Explore the data using descriptive statistics.
5. Analyze numerical columns such as meal price, customer rating, preparation time, and rider distance.
6. Interpret the results to understand patterns in the dataset.

## How to Run
1. Download or clone this repository.
2. Open `Module3_Mat_Stats.ipynb` using Jupyter Notebook or Google Colab.
3. Make sure the required Python libraries are installed.
4. Upload the `Swiggy_Analysis.csv` dataset to the appropriate location.
5. Run the notebook cells in order.

This project demonstrates how Python and statistical techniques can be used to explore food delivery data and understand information about meal prices, customer ratings, preparation times, and rider distances.
